# ТЗ: веб-приложение «Бинарные лампочки»

## 1. Цель и ключевой принцип

Разработать учебное веб-приложение на React, моделирующее ряд бинарных лампочек
для обучения детей двоичному счёту.

Пользователь должен иметь возможность:

- включать и выключать лампочки кликом;
- добавлять новые лампочки;
- удалять любые лампочки, включая последнюю.

Ключевой принцип:

- приложение является цифровой моделью лампочек для двоичного счёта;
- приложение НЕ выполняет переносы, НЕ подсказывает и НЕ решает задачу за ученика;
- во время игры итог не отображается;
- итог вычисляется только по нажатию кнопки «Проверить» и служит проверкой,
  а не подсказкой.

## 2. Технологии

- React
- TypeScript
- Vite
- CSS
- без UI-фреймворков
- без backend
- полностью client-side
- состояние приложения через React state / useReducer
- скрипты проекта: `npm run dev`, `npm run build`, `npm run lint`, `npm run preview`

## 3. Игровое поле

```text
 ○    ○    ○    ○    ○
 │    │    │    │    │
```

- Ряд лампочек выровнен по правому краю экрана.
- Значение лампочки определяется её позицией: самая правая означает 1, левее — 2,
  левее — 4, левее — 8 и так далее (каждый шаг влево удваивает вес разряда).
- Клик по лампочке переключает её состояние.
- Включённое и выключенное состояния визуально различаются.
- При наведении на лампочку и на крестик курсор мыши меняется (`pointer`).
- Высота лампочки не меньше 50px, ширина не меньше 20px.
- У каждой лампочки есть кнопка-крестик для удаления, даже если она единственная.
- Удалить можно все лампочки: пустое поле — допустимое состояние.
- Новые лампочки добавляются слева (слева появляется новый старший разряд).
- Количество лампочек не ограничено. Если ряд не помещается по ширине,
  он прокручивается по горизонтали.
- При удалении лампочки из середины разряды пересчитываются по позиции:
  лампочки левее удалённой сдвигаются на разряд младше.

---

## 4. Кнопки

В приложении три кнопки:

1. **Проверить** — показать итог текущего состояния. Игра при этом не завершается,
   редактирование продолжается.
2. **Начать заново** — сбросить игру к исходному состоянию (5 выключенных лампочек)
   и скрыть итог.
3. **Добавить лампочку** — добавить одну выключенную лампочку слева.
   Изначально лампочек 5; при сбросе снова 5.

Любое действие с полем — переключение, добавление или удаление лампочки —
скрывает ранее показанный итог.

---

## 5. Результат

- Во время игры результат не отображается: ученик видит только включённые
  и выключенные лампочки.
- Итог показывается по кнопке «Проверить» в двух видах: десятичное значение
  и двоичная запись.

Например:

```text
Результат: 19 (10011)
```

- Двоичная запись содержит ровно столько цифр, сколько лампочек на поле:
  каждая лампочка — один разряд. При пяти лампочках и включённой только правой
  итог выглядит так:

```text
Результат: 1 (00001)
```

- Если лампочек не осталось, итог: `Результат: 0 (0)`.
- Никаких переносов, разбора суммы и других подсказок приложение не показывает.

---

## 6. Интерфейс

- Интерфейс минималистичный и визуально напоминает физическую математическую игру,
  а не компьютерную.
- Подписи весов разрядов (1, 2, 4, 8…) под лампочками не показываются:
  ученик считает сам.
- Тексты интерфейса на русском языке.
- Крестик удаления виден всегда (не только при наведении) — интерфейс рассчитан
  на детей.
- Доступность:
  - лампочка — кнопка с `aria-pressed` и понятным `aria-label`;
  - крестик — кнопка с `aria-label` «Удалить лампочку»;
  - все элементы доступны с клавиатуры, у интерактивных элементов виден фокус;
  - блок с итогом имеет `aria-live="polite"`, чтобы результат озвучивался
    скринридером.

---

## 7. Адаптивность

Приложение рассчитано на desktop от 1024px. Мобильная версия не требуется.

## 8. Модель состояния

```ts
type Lamp = {
  id: number // стабильный ключ React, не меняется при добавлении и удалении соседей
  on: boolean
}

type State = {
  lamps: Lamp[] // слева направо; lamps[0] — крайняя левая (старший разряд)
  nextId: number
  showResult: boolean
}

type Action =
  | { type: 'TOGGLE'; id: number }
  | { type: 'ADD' }
  | { type: 'REMOVE'; id: number }
  | { type: 'RESET' }
  | { type: 'CHECK' }
```

- Начальное состояние: 5 лампочек, все выключены, итог скрыт.
- `TOGGLE`, `ADD`, `REMOVE`, `RESET` скрывают итог (`showResult: false`).
- `CHECK` показывает итог (`showResult: true`).
- У каждой лампочки есть стабильный `id`, и в качестве ключа React используется
  именно он, а не индекс. Иначе при добавлении лампочки слева индексы сдвигаются,
  React переиспользует DOM-узлы и состояние перескакивает на соседнюю лампочку —
  возникает визуальная вспышка.
- Десятичное значение — свёртка слева направо:
  `value = value * 2 + (lamp.on ? 1 : 0)`. Для точности при большом числе
  лампочек используется `BigInt`.
- Двоичная запись — строка из `0`/`1` по числу лампочек; для пустого поля — `0`.

## 9. Компоненты

- `App` — состояние (`useReducer`), раскладка.
- `Bulb` — одна лампочка и кнопка-крестик удаления.
- `BulbRow` — ряд лампочек.
- `Controls` — кнопки «Проверить», «Начать заново», «Добавить лампочку».
- `Result` — вывод итога.

- [ ] Включённая и выключенная лампочки визуально различаются.
- [ ] У каждой лампочки есть крестик удаления; удалить можно все лампочки.

- [ ] При переполнении ряд прокручивается по горизонтали.
- [ ] «Начать заново» возвращает 5 выключенных лампочек и скрывает итог.
- [ ] Во время игры итог не виден.
- [ ] «Проверить» показывает `Результат: N (битовая строка)`, где длина битовой
      строки равна числу лампочек.
- [ ] После «Проверить» игра не завершается, редактирование продолжается.
- [ ] При 0 лампочек «Проверить» показывает `Результат: 0 (0)`.
- [ ] Любое изменение поля скрывает показанный итог.
- [ ] Лампочки выровнены по правому краю, самая правая означает 1.
- [ ] Высота лампочки не меньше 50px, ширина не меньше 20px.
- [ ] Приложение корректно работает при ширине от 1024px.
